📋 Procedura Completa di Stress Test

PRE-TEST (Setup)

  1. Verifica ambiente (database, API, email, WhatsApp, Telegram, SDI)
  2. Esecuzione backup completo database
  3. Backup file sito web
  4. Caricamento dataset di test (5 clienti, 3 preventivi, 2 cantieri, 9 dipendenti, 5 fornitori, etc.)
  5. Test connettività API esterne
  6. Notifica team di inizio stress test

Fase 1: Canali di Contatto (49 minuti)

Obiettivo: Verificare che tutti i canali di contatto creino lead automaticamente e sincronizzino dati con CRM
Moduli interessati: Chatbot, Form sito, Email, WhatsApp, Telegram, CRM
Dato critico: Lead deve essere visibile in gestionale CRM entro 5 minuti dalla ricezione
  • Test Chatbot homepage: scrivi messaggio, verifica lead in CRM
  • Test Form sito: compila con dati test, allega PDF e foto, verifica lead e allegati
  • Test Email: invia da test@email.com, verifica risposta automatica e lead in CRM
  • Test WhatsApp: invia messaggio da numero test, verifica risposta bot e lead creato
  • Test Telegram: invia messaggio a bot, verifica ricezione e lead in CRM

Fase 2: Sito Web (70 minuti)

Obiettivo: Verificare navigazione, performance, responsiveness e SEO base
Moduli interessati: Tutte le pagine pubbliche
Target di performance: Homepage < 1.5s, pagine servizi < 1.2s
  • Navigazione completa: homepage, 8 pagine servizi, chi siamo, portfolio, blog, contatti
  • Test Desktop: verifica caricamento, menu, CTA, chatbot
  • Test Mobile (iPhone + Android): responsiveness, touchscreen, form compilabili
  • Performance: Lighthouse score > 80, loading < 3s
  • Carico simulato: 50 utenti contemporanei, zero errori 502/503

Fase 3: Gestionale — Moduli Core (95 minuti)

Obiettivo: Verificare CRUD (Create, Read, Update, Delete) per ogni modulo e integrazioni tra moduli
Moduli: CRM, Preventivi, Ordini, Cantieri, Rapportini, Fatturazione, Manutenzioni, Magazzino, Personale
Test su mobile: Firma digitale, check-in GPS, visualizzazione dati
  • CRM: Crea lead manuale → cerca per nome/email → modifica → visualizza comunicazioni
  • Preventivi: Crea preventivo con 3+ righe → verifica calcoli (sconto, IVA) → allega PDF → invia cliente
  • Ordini: Converti preventivo → ordine → allega contratto → richiedi firma digitale
  • Cantieri: Crea da ordine → assegna operai → crea SAL progressivi → verifica progress %
  • Rapportini: Su mobile: crea rapportino con ore/materiali → firma digitale → allega foto GPS
  • Fatturazione: Genera fattura da SAL → verifica XML SDI → invia a Agenzia Entrate
  • Manutenzioni: Verifica creazione automatica dopo completamento cantiere
  • Magazzino: Verifica scarico materiali da rapportini → giacenza aggiornata
  • Personale: Check-in mobile con GPS → check-out → verifica ore nel rapportino

Fase 4: Automazioni (50 minuti)

Obiettivo: Verificare il flusso completo automatico da lead a fattura, con verifica di ogni trigger
Timeline complessiva: Tutte le operazioni devono essere automatiche (eccetto firma cliente)
  • Lead da form → Lead in CRM (entro 5 min)
  • Preventivo accettato → Ordine creato automaticamente
  • Ordine firmato → Cantiere creato automaticamente
  • Cantiere 100% → SAL creato, email cliente per approvazione
  • SAL approvato → Fattura creato, XML generato
  • Fattura → Inviato a SDI (Agenzia Entrate)
  • Cantiere completato → Manutenzione futura programmata

Fase 5: Moduli Aggiuntivi (50 minuti)

Obiettivo: Verificare moduli di supporto: costi, campagne, appuntamenti, agenti, ticket, gemello digitale, documentazione
  • Costi: Registra spesa → assegna a cantiere → verifica impatto margine
  • Campagne: Crea campagna → invia email/WhatsApp → tracking ROI
  • Appuntamenti: Crea sopralluogo → reminder 24h+1h → mappa → notifica mobile
  • Agenti: Performance agosto → provvigioni calcolate → bonus automatico
  • Ticket: Cliente segnala guasto → ticket creato → workflow → rapportino auto
  • Gemello Digitale: Cliente accede portale → visualizza impianti → storico manutenzioni
  • Documentazione: Repository cantiere → preventivi, contratti, SAL, fatture, rapportini

POST-TEST (Cleanup)

  1. Raccolta risultati e log
  2. Generazione report con statistiche
  3. Eliminazione record di test dal CRM
  4. Ripulitura database
  5. Notifica team con risultati
